# Contributing

HIDVIA is a public-interest, open-source research prototype. Contributions, improvements and charitable adaptations are welcome under the MIT license, subject to the original contributors' authority to license their code.

Please do **not** submit patient-identifiable data, real medical photos, access credentials, partner datasets or private clinical records. Use generated fictional data in issues, pull requests and screenshots. Include tests when changing the server/API. Mark clinical model changes as **research only** until independently validated. Do not state that partner organisations have endorsed a release without explicit permission.
